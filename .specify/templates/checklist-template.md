> ## Checklists são "testes unitários para o português"
>
> Um checklist NÃO valida se o software funciona — isso é papel dos testes.
> Ele valida se os **requisitos estão bem escritos**.
>
> ❌ Errado: "Verificar se o botão clica corretamente"
> ✅ Certo: "'Exibição destacada' está quantificada com tamanho/posição específicos?" *(clareza)*
>
> Metáfora: se a spec é código escrito em português, o checklist é a suíte de testes dela.

**Rastreabilidade**: ao menos 80% dos itens DEVEM citar uma referência —
`[Spec §X.Y]` ou um marcador `[Lacuna]` / `[Ambiguidade]` / `[Conflito]` / `[Premissa]`.

**Itens são append-only**: ao regerar, continue a numeração `CHK###`; nunca remova itens existentes.
